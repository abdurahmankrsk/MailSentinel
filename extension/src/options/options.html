MailSentinel

Scan the email you are reading, without leaving your inbox.

Server

Where your MailSentinel instance is running. The default matches the local JAR from the project README. Changing this to any other address needs your permission, which Chrome will ask for when you save.

Anonymous scans work and return the full deterministic result. A token is only needed to draw on your plan's AI analysis quota.

Gmail raw access optional

Without this, the extension reads the message from the page, which has no authentication headers — so SPF, DKIM and DMARC checks stay inconclusive. Granting Gmail read access lets it fetch the true message source and check them properly. Gmail only; Outlook always reads from the page.
